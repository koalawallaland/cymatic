how to write patterns

s("bd*4") four kicks a bar. Drums: bd sd cp hh oh rim.
~ is a rest. [a b] squeezes into one step. <a b> takes turns each bar. x*2 repeats, x!2 copies.
note("g2 eb2") plays notes; chord("<Cm Ab>") plays chords.

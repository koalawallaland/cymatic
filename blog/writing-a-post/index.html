How to write a post here

  1. Create src/content/blog/your-post-name.md
  2. Add frontmatter:
---
title: "Your title"
date: 2026-07-08
description: "One line for RSS and previews."
tags: ["whatever"]
draft: true   # keeps it hidden until you're ready
---
  1. Write markdown below it. Images go in public/ and are referenced as /image-name.png.
  2. Flip draft: true off (or delete the line) to publish.

That’s the whole workflow. Commit, push, and the deploy runs itself.
